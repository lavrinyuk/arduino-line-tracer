# Arduino Line Follower Robot
Простой робот для езды по линии на Arduno UNO и L298n

Скетч для управления двухколесным роботом-трекером линии на базе Arduino, драйвера моторов L298N и двух ИК-датчиков.

## Компоненты
- Arduino (Uno / Nano)
- Драйвер моторов L298N
- 2х ИК-датчика линии
- 2х DC мотора (желтые TT-моторы)
- Питание (2x Li-ion 18650)

## Подключение (Pinout)
| Компонент | Вывод L298N / Датчик | Пин Arduino |
| :--- | :--- | :--- |
| **Левый мотор PWM** | ENA | D3 |
| **Левый мотор IN1** | IN1 | D2 |
| **Левый мотор IN2** | IN2 | D4 |
| **Правый мотор IN3**| IN3 | D7 |
| **Правый мотор IN4**| IN4 | D8 |
| **Правый мотор PWM**| ENB | D5 |
| **Левый датчик**   | OUT | D13 |
| **Правый датчик**  | OUT | D12 |

## Возможности
- Раздельное управление скоростью (ШИМ) и направлением вращения.
- Алгоритм мягкого поворота (подтормаживание внутреннего колеса).
- Встроенный метод диагностики `testHardware()` для проверки моторов и датчиков через Serial Monitor.
